# Revisión del código actual de Nightingale API

**Fecha:** 2026-11-18. **Plan:** [tres etapas](plan.md).

El informe reúne la revisión inicial y cuatro pasadas sobre críticos, fallos medianos y menores, simplificación, y reutilización de código, variables y constantes. Las revisiones usan el árbol actual y el estado de Git, sin abrir diffs. Las fuentes son la [autorización por objeto](../../docs/authorization-rbac-abac.md), el [contrato HTTP](../../docs/api-v1.md), el [esquema PostgreSQL](../../docs/database-schema.md) y la [especificación clínica](../../docs/patient-clinical-record.md).

## Cobertura y verificación de críticos

- El análisis estático recorrió las 48.642 líneas de los 351 archivos Python en `src`, `migrations`, `scripts`, `tests` y `test-support`. Incluyó el inventario de rutas y llamadas, límites de transacción, puntos de commit y declaraciones SQL. En los routers montados, rastreó 110 rutas hasta autenticación de dispositivo u OIDC y cuatro hasta entradas públicas del contrato. Este control de llamadas no acredita por sí solo autorización por objeto ni una lectura manual de cada línea.
- La lectura manual siguió desde HTTP hasta persistencia y reglas SQL los recorridos de acceso y revocación, permisos por cuenta y sección, aceptación, recibos, captura, delta y SSE. Contrastó los ámbitos de ficha y objeto, los cambios de agenda y citas, y las transiciones clínicas de altas, correcciones, versiones e invalidaciones. Queda pendiente completar y acreditar la lectura manual por archivo del resto del árbol.
- Para CR-01 se conserva la comprobación anterior del catálogo PostgreSQL. La revisión de código confirma la edición y las dos rutas de lectura afectadas. Quedan pendientes las pruebas de rechazo de la corrección.
- Para CR-02 a CR-05, los cuatro recorridos ejercitaron HTTP y PostgreSQL 18 con una base de prueba nueva y datos ficticios. Se sustituyó solo la verificación del proveedor OIDC para emitir los tokens iniciales. Los datos y la base de prueba se retiraron al salir. Los 14 tests existentes de informes y especialidad pasaron y los recorridos focales mostraron los defectos que faltan en esa cobertura.
